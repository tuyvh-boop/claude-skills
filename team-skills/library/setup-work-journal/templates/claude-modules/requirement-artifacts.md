### Tài liệu requirement trong task (BA / PMA)

| Loại | Đích trong folder task | Kiểu |
|---|---|---|
| ghi chú requirement, phân tích nghiệp vụ | `requirement/<yy-mm-dd>-<slug>.md` | tích luỹ |
| câu hỏi chờ trả lời (dev, tester, khách) | `requirement/open-questions.md` | singleton |
| lịch sử thay đổi requirement | `requirement/changelog.md` | singleton |
| chốt một quyết định + lý do | `decisions/<yy-mm-dd>-<slug>.md` | tích luỹ |
| ghi chú buổi họp / trao đổi | `meetings/<yy-mm-dd>-<slug>.md` | tích luỹ |

- Ghi theo vai trò (dev, tester, PMA), không ghi tên người trong tài liệu sẽ gửi đi.
- Không chép thông tin khách hàng (tên shop, domain, email) — mô tả chung.
