### Nguyên liệu dựng skill AI — `build-skills/`

- Mỗi skill đang ấp ủ 1 folder `build-skills/<tên-skill>/` (không ngày): `README.md` (vì sao cần, nguyên liệu, nguồn tham khảo) +
  `plan.md` (plan thiết kế, sửa đè qua các vòng).
- Ý tưởng chưa bắt đầu → 1 mục trong `build-skills/_backlog.md` (pain gì, chưa làm vì sao).
- Ship xong → chuyển folder sang `build-skills/_archive/`, xoá mục backlog. File skill hoàn chỉnh không nằm ở đây.
