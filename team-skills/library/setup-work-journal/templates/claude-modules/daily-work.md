### Nhật ký theo ngày — `daily-work/<yy-mm>/`

- 1 ngày 1 file `daily-work/<yy-mm>/<yy-mm-dd>.md`; 1 kỳ (tuần, nhiều ngày) 1 file `<yy-mm-dd>--<yy-mm-dd>.md` ở folder tháng
  của ngày bắt đầu. Chạy lại cùng ngày → cập nhật file đó, không tạo bản 2.
- Chỉ ghi **việc đã xảy ra**: task nào, làm gì, áng chừng bao lâu, họp, support. Không ghi kế hoạch ngày mai.
- Trỏ link tới folder task thay vì chép nội dung.
