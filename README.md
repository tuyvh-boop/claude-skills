# My Claude Code Skills

A collection of [Claude Code](https://claude.com/claude-code) skills used in day-to-day engineering work.

## Structure

- `personal-skills/` — skills authored individually (planning, code review, git workflow, dev-journal, Shopify app support tooling, etc.)
- `team-skills/` — shared team skill library (Jira/CRM helpers, review checklists, Chrome automation, onboarding material)

## Usage

Each skill directory follows the Claude Code skill format — a `SKILL.md` describing when/how to invoke it, plus optional `references/`, `scripts/`, and `templates/` supporting files. Symlink (or copy) a skill folder into your `~/.claude/skills/` directory to make it available.

Note: some skills reference internal company tooling/URLs specific to the original team's environment and may need adaptation to work elsewhere.
